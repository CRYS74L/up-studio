# UP Studio

<img src="public/brand/up-studio.svg" alt="UP Studio" width="112" height="112" />

个人创作者的数据工作区。当前开发版本 **v0.1.0-dev.25**。

## 独立本地部署

网站运行于 http://localhost:5173/，使用固定 Node、编译后的网页与 Worker、独立 SQLite 数据库。日常运行不需要开发服务器或 Codex。

- 唯一计划任务 BilibiliCreatorInsights-Local-25758：当前用户登录后启动，普通权限，不保存密码。
- 无控制台窗口的 Windows 后台宿主 ServiceHost.exe 监督子服务，异常退出后退避恢复；手动停止不会重拉。
- 每 15 分钟自动采集，轮转日志、每日备份；仅自动管理程序创建并登记的备份文件。
- 数据和凭据保存在项目内 .local-runtime，不进入 Git。首次通过 SQLite online backup 迁入，不覆盖原 Wrangler 数据库。
- 安装前后核对其他任务、Run/RunOnce 注册项及启动文件夹的哈希；管理命令只操作核验归属的唯一任务。

管理命令：pnpm local:start、pnpm local:stop、pnpm local:update。详细安装、更新和移除说明见 [runtime/README.md](runtime/README.md)。

升级先构建，等进程退出、端口释放及任务 Ready 后切换；健康检查失败时同时恢复旧运行脚本、配置和发布指针，保留数据库的新数据。

## 产品结构

- **概览**：核心指标和真实小趋势、横向吸引力排行、最近稿件、观看时长与进度组合图。
- **稿件**：网格/列表、标题/BV 搜索、时长筛选与排序、多选分析；独立详情分为表现、观众、留存与趋势。
- **分析**：作品对比、时间趋势、指标关系三个任务。选择器使用草稿和显式应用；最多四项指标，独立单位图表和原始数据表。
- **数据源**：连接、本地服务状态、指标可用清单和最近二十次同步记录；断线优先显示失联，不沿用旧缓存声称正常。
- **设置**：当前快照导出、凭据管理、本地数据说明。

全新设计系统采用清新的浅粉、蓝、青、淡紫与中性色，内嵌当前字体、共享布局弹簧动效、对称弹层转场、键盘焦点及减少动态效果支持。使用 HTML / React / Motion，并非 SwiftUI 原生组件。

## 数据口径

同批次读取真实汇总及稿件，无数据不回退到演示数字。概览从当前快照回溯完整一个月，例如9月5日对应8月5日；缺少对应日历史不拿其他日期替代。

封标吸引力使用 tm_star / 10（0–5星）；动态脱敏的 tm_rate 不作为绝对点击率。平均观看进度不同于完播率。不同口径的比例不包装成逐级漏斗，缺少定义的年龄分组不猜测区间。逐日趋势按真实日期对齐，不把缺失日补零。

**绝对曝光、绝对点击率、推荐/搜索来源仍未接入**，不计入已接入指标可用率。云端备份、历史导入、AI 对话也未实现。

## 开发与验证

使用 pnpm install --frozen-lockfile 安装固定依赖。检查命令为 pnpm typecheck、pnpm test、pnpm test:runtime、pnpm build。开发预览使用 pnpm dev --host localhost --port 5174，避免占用独立服务的5173。

设置 PLAYWRIGHT_BASE_URL=http://localhost:5173 后运行 pnpm test:ui。界面用例使用独立夹具，不向B站反复请求。密钥仅留在 .dev.vars 或独立运行目录。

验收包括单元测试、D1事务回滚、完整发行状态回滚、桌面/手机/平板交互、独立进程父链、正常停启、异常恢复和启动清单审计。实际注销/重启后的登录周期仍需用户自行验收。

安装前后其他250条启动记录一致；跨时段复核发现Windows内部 RefreshCache 任务的一项定义变化，项目未操作或恢复该任务。所有服务管理仍限定于本项目唯一任务。
