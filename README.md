# 哔哩哔哩数据看板 · 创作空间

个人私有的 B 站创作者数据工作区，React / Vite + Hono / Cloudflare Workers + D1。

当前开发版本：**v0.1.0-dev.13**。

## 已实现

- iOS / iPadOS 风格的响应式界面：悬浮材质导航、系统字体、大标题、分组指标、分段控件、深浅主题与减少动态效果支持。网页使用原生 HTML 与 React 组件，不依赖 SwiftUI / UIKit。
- 概览展示真实累计指标、可切换的稿件表现图、可读数据表、最近发布与数据健康；旧快照明确显示采集时间。
- 稿件支持标题 / BV 搜索、排序、定位链接、前后切换；详情按核心数据、观看质量、观众画像、快照趋势分组。
- 内容矩阵、联合分析、图层选择、稿件范围和相对尺度；缺失数据保留为空。
- 看板内扫码连接 B 站。采集请求最多 4 路并发，网络错误退避重试，登录失效 / 风控停止重试；完整校验分页数量与重复稿件，单条 SQL 领取采集任务以避免重复运行。
- 汇总与稿件按同一采集批次读取；加权观看时长只使用有效数据的权重，不将缺失互动数据当成零；与当前快照对应日期的一个月前比较，展示实际基准日期，缺少对应日数据时不补造变化。
- 本地统计生成的创作建议、当前快照 JSON 导出。建议不调用 AI，导出不含凭据、不含完整历史。

## 启动与验证

```sh
pnpm install --frozen-lockfile
pnpm dev --host localhost
pnpm typecheck
pnpm test
pnpm build
```

本地预览默认为 `http://localhost:5173/`。浏览器回归测试使用运行中的开发服务器：

```powershell
$env:PLAYWRIGHT_BASE_URL='http://localhost:5173'
pnpm test:ui
```

浏览器测试通过独立测试夹具覆盖空数据、错误、快照变更及交互，不向 B 站反复发送测试请求。实际界面只读取本地或部署数据库，不回退到演示数据。

首次使用需准备 D1 并应用 migrations 中的迁移，配置 `.dev.vars` 中的会话加密密钥。已有数据库无需重新初始化或导入覆盖。所有真实凭据必须留在 `.dev.vars` / Cloudflare Secrets 中。

## 数据口径与边界

- `tm_star / 10` 表示封标吸引力的 0–5 星评分；动态脱敏的 `tm_rate` 不用于计算绝对点击率。
- **绝对曝光量、绝对封面点击率、推荐 / 搜索流量来源尚未接入。** 已接入指标可用率不包含这三类，不能解释成全部计划指标完整。
- 概览从当前快照的本地日期与时刻回溯完整一个月（Asia/Shanghai），例如 9 月 5 日对应 8 月 5 日；31 日在短月份中收敛至月末。不按自然月或固定 30 天计算。仅使用基准日内、不晚于对应时刻的最新快照；缺少该日数据时不以其他日期替代。它比较累计指标，不将累计总量伪装成单月新增量。
- 非公开 B 站接口可能发生变化，成功的一次采集不保证长期无故障。页面保留原快照并展示本次失败状态。
- Cloudflare 数据库 ID 仍需配置，当前完成的是本地验证。云端每 15 分钟的 Cron 定义只有实际部署后才会执行。
- 历史 CSV / Excel 导入、Google Drive 自动备份 / 恢复、AI 对话尚未接入。DeepSeek 密钥管理与连接测试保留，但不代表 AI 分析已实现。前端明确标注未接入功能。
