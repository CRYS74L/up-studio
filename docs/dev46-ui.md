# dev.46 — 图表悬停、时间刷新与对话控件

- 所有路由进入时滚动到 0，移除一级页面的滚动位置记忆。
- 顶部及数据源的同步时间共用 FreshnessAge。每秒只更新文字组件；分钟边界测试验证不请求数据、不重渲染父页面。
- 旧画面退出距离改按完整窗口范围计算，避免完成移动后仍有一截位于侧栏后方。保留用户的速度曲线与 530 ms 设置。
- 图表使用 ECharts SVG renderer，保留原有数据、平滑曲线与生长动画。针对用户反馈的 Canvas 悬停重绘期间侧栏出现污染，候选页沿多个日期连续悬停未复现；不把这一结果描述为已证明底层 GPU 原因。
- 光学配置或尺寸变化时产生新的 SVG filter URL，避免复用旧图形缓存；实际对比 0 与 120 折射强度的画面。侧栏底色、外阴影增加独立控制，消除调节值被固定样式覆盖的问题。
- 复用 ChatGPT 页面实际引用的五个 SVG 控件图标。AI 工具栏合并到分析标签栏，调整桌面空白对话、手机标签栏、输入框和 Dock 的间距，保留已有对话功能。
- 立即同步改为轻底色、细描边的胶囊按钮。

验证仅在侧边浏览器进行：图表 SVG/tooltip、材质两端参数的图像与实际样式、桌面/390×640、一级页面离开 1440 px 后重新进入 0 px。原 ChatGPT 服务代码和账号数据未复制；图标来源单独记录。
