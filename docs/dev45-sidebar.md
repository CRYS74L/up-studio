# dev.45 — 恢复侧栏基线与穿过侧栏的转场

纠正 dev.42–44 扩大的改动范围：加入光学材质不应改变侧栏底色、投影或切页路径。

- 按 dev.38 的样式恢复侧栏底色 `var(--glass)`、边框 `var(--glass-border)`、投影 `var(--shadow)`。浅色实测 rgba(255,255,255,.82) 与 0 3px 18px rgba(44,65,104,.027)。
- 侧栏仅保留单独背景折射层，使用原 rdev SVG 折射链及用户参数；不再挂载光标跟随的双混合遮罩/高光层、内部布局变换或大投影。不是以加厚材质掩盖错误。
- 页面级快照范围扩展到窗口，移动内容只在窗口边缘裁切。允许页面实际经过侧栏后方；局部卡片的切换仍限制在卡片内。
- 保留用户选择的连续推移、阻尼 1、530 ms。未更换字体或改动数据。

验收仅在 Codex 侧边浏览器：连续截取横向切换中途画面，观察内容延伸至窗口左侧；反复切换四个一级页面并连续移动鼠标后无残留快照、无横向溢出、无运行错误。本轮未复现随机材质断块；不把静态截图或测试通过等同于保证所有运行时条件。
