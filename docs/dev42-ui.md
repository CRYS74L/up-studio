# dev.42 — 转场边界、玻璃参数及对话交互

## 用户确认的参数
在用户正式页面读取到：连续推移、弹簧阻尼 1、时长 530 ms。此次没有修改弹簧计算、速度曲线或用户存储的上述设置。

## 修复
- 转场快照外框保持固定，只移动其内部视觉层；新页面按主内容区的固定边界裁切。避免旧内容横向滑到侧栏下方。65 个测试包含两种方向的逐帧边界验证。
- 主题快照从真实 studio 边界取宽度，不再使用包含滚动条预留区的 innerWidth。侧边浏览器实测真实与快照宽度均为 1269.60 px，主区域均为 1049.60 px、左边界 220 px。
- 重新进入详情或分析子页面，从顶部开始；返回一级稿件列表仍保留列表位置。实测详情离开前 1440 px，重新进入 0 px。
- 侧栏选中与悬停轮廓改为胶囊。

## 液态玻璃
- 接入 rdev/liquid-glass-react 的完整光学、高光与边缘层，原文件与 shader-utils 保留来源授权。当前上游 master：ac48eab18d1f7f444ae30002d240cae29c863a21。
- 与原组件的集成差异：用 ResizeObserver 跟随实际容器尺寸；控件几何保持固定，elasticity=0；内容仍独立于光学层。隐藏控件不生成零尺寸材质；修复原库在响应式隐藏时生成零宽纹理的边界错误。
- 4 个预设：原站卡片演示、原库默认、原按钮光学参数、轻白阅读。在线演示读到卡片 100 / 0.5 / 140 / 2，按钮 64 / 0.1 / 130 / 2。
- 开放四种折射模式、强度、磨砂、饱和度、色差、白色遮罩、阴影和亮背景补偿。侧栏、Dock、回到顶部和提示胶囊共用；恢复材质默认不会改动转场参数。
- 移除包装层额外的合成上下文，避免隔离实际背景采样；已将共用组件与原组件直接渲染作同参数画面对照。
- 原站：https://liquid-glass.maxrovensky.com/ 。Safari / Firefox 的边缘位移仍受浏览器支持限制。
