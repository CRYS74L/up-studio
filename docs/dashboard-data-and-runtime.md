## 概览与比较

- 粉丝量：账号粉丝总量，来自 fans/stat/num 的 total_num，不使用稿件涨粉之和。
- 播放量：本批稿件累计播放之和；平均播放量按稿件数计算。
- 平均互动量：每篇的点赞、评论、弹幕、收藏、投币、分享之和，再按稿件数平均；缺失任何分项时不假装完整。
- 每项独立选择比较基准：上月同日，缺失则上周同日，再缺失则昨天；月末按实际月份天数截断，不按自然月汇总。标签使用“相比上月”等。
- 封标点击率采用创作中心的星级展示，数值为 tm_star / 10。tm_rate 不能作为绝对点击率；绝对曝光与百分比点击率仍保持不可用。排行动态设置坐标范围，两端圆角，悬停查看完整标题与原值。

## 联合分析

组合图包含账号新增关注/取消关注双折线、播放柱/涨粉线、播放柱/互动线、观看组合图、自定义最多四层指标。各指标保留自己的单位和坐标轴。

观看图按投稿从旧到新排列，每篇短标题均显示，悬停可查看全名，图表适应可用宽度。柱表示平均播放百分比，折线可切换平均播放时长或 3 秒跳出率。“平均播放时长与完播率”为用户指定标题，其中播放百分比不等同于完整看完人数比例。

## dev.17 交互调整

界面底色、材料和滚动条恢复中性灰。局部强调粉色与图表颜色提高明度，折线使用轻微单调平滑和透明度渐变，缺失值仍断开。分析改为单层主题选择，账号与全稿件统计隐藏稿件选择器，作品对比、自定义等主题保留选择。日期轴不自动跳过标签。

侧栏默认展开，可收起；工作区入口提供连接与设置管理。动态图标采用 MIT 开源库 @animateicons/react 0.5.0（https://github.com/Avijit07x/animateicons），由悬停、聚焦、点击触发，响应减少动态效果设置。下拉菜单统一圆角浮层，支持方向键、确认、Escape 和点击外部关闭。

验证：24 项数据测试，51 项桌面/手机/平板交互测试，以及生产构建通过。实际查看17篇稿件组合图和近30天粉丝曲线。

## dev.18 精简交互与账号资料

分析入口固定为“全局统计 / 稿件分析”两个滑块选项。全局统计同页排布四张图；稿件分析共享一次选稿，展示对比、表格、自定义叠加、时间趋势和关系分析。倾斜坐标标签向右排列。

概览四项指标及普通信息卡取消悬停反馈。稿件卡仅封面、标题与封面内选择按钮可交互，数据区不跳转。滑块悬停恢复中性背景；黄色改为柔和沙金色。侧栏固定展开，图标容器统一对齐，数据源使用服务器图标；同步使用 AnimateIcons RefreshCwIcon。

UP主姓名、头像和UID由当前登录会话的 nav 接口读取。账号面板提供个人主页、扫码添加账号和已连接账号切换。不同账号使用独立的稿件、快照、趋势、粉丝和采集记录表，现有数据留在原账号下，不迁移或删除。昵称头像更新缓存5分钟。单账号资料已用真实登录核验；账号切换数据隔离通过内存数据库测试，未替用户切换实际登录账号。

互动量 = 点赞 + 投币 + 收藏 + 评论 + 分享 + 弹幕，是累计互动次数，不是去重人数；平均互动量 = 同批次全部稿件互动量总和 / 稿件数。有分项缺失则平均值保持为空。2026-09-07 本次核对：83224 / 17 = 4895.53。

验证：25项数据/账号隔离测试、54项桌面/手机/平板交互测试及生产构建通过。

## dev.19 参考页面对齐

已查看用户打开的 ChatGPT 聊天/工作胶囊滑块、B站首页卡片，以及创作中心年龄、兴趣、地域和播放趋势。滑块采用中性轨道与白色胶囊，保留可打断位移动画。

概览四项指标共同选择一个具有完整基准的周期（月、周、昨日顺序），不再逐项混用。周期文字在上，方向与百分比在下；当前实测统一为较昨日变化。共同基准缺失时四项都不计算变化。

稿件默认密度提高：常见桌面4列、宽屏5列。播放与弹幕放在封面底部，外显指标为点击率星级、平均播放时长（min/s）与平均播放百分比。涨粉不再带“归因”前缀；整数万数移除尾随小数，短日期使用点号分隔。两个播放组合图各占整行。

分布区复用创作中心的信息结构：纵向年龄柱图、词云与分页排行、地域地图与分页排行；颜色适配本站。地图数据来自阿里云 DataV 的 https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json ，文件保存在 public/maps/china.json，无在线地图服务依赖。环图各段圆角留缝，极小扇区有最小可见角度，真实比例以图例为准。折线提高平滑度并增强顶部到底部透明渐变。

补充修正：环图不显示坐标轴；后台快照更新保持正在查看的稿件详情标签。验证通过26项数据测试、57项跨设备交互测试及生产构建。
