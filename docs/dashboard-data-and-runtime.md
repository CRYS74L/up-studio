## 概览与比较

- 粉丝量：账号粉丝总量，来自 fans/stat/num 的 total_num，不使用稿件涨粉之和。
- 播放量：本批稿件累计播放之和；平均播放量按稿件数计算。
- 平均互动量：每篇的点赞、评论、弹幕、收藏、投币、分享之和，再按稿件数平均；缺失任何分项时不假装完整。
- 每项独立选择比较基准：上月同日，缺失则上周同日，再缺失则昨天；月末按实际月份天数截断，不按自然月汇总。标签使用“相比上月”等。
- 封标点击率采用创作中心的星级展示，数值为 tm_star / 10。tm_rate 不能作为绝对点击率；绝对曝光与百分比点击率仍保持不可用。排行动态设置坐标范围，两端圆角，悬停查看完整标题与原值。

## 联合分析

组合图包含账号新增关注/取消关注双折线、播放柱/涨粉线、播放柱/互动线、观看组合图、自定义最多四层指标。各指标保留自己的单位和坐标轴。

观看图按投稿从旧到新排列，每篇短标题均显示，悬停可查看全名，图表适应可用宽度。柱表示平均播放百分比，折线可切换平均播放时长或 3 秒跳出率。“平均播放时长与完播率”为用户指定标题，其中播放百分比不等同于完整看完人数比例。

## dev.18 精简交互与账号资料

### DeepSeek 数据和提示词

实现见worker/ai-analysis.ts，提示词版本creator-review-1。支持官方V4 Flash与V4 Pro；依据官方API文档（https://api-docs.deepseek.com/api/create-chat-completion/）使用JSON输出。

数据由服务端从当前账号数据库构造，包括所选稿件的发布时间、时长、已验证的播放/观看/互动/涨粉指标、近期播放序列、年龄性别及前列地域/兴趣摘要、30天账号变化。只允许指定字段，不将密钥、登录会话和混淆值交给模型。发送前可以查看同一份数据与提示词。

结果为核心判断、带证据与置信度的发现、可执行实验及判断边界。证据的videoId和metric由服务端核验，显示值从真实输入补齐，点击证据可回到稿件。提示词明确区分星级、观看百分比、累计互动与去重人数，要求考虑稿件时长、上线时间和样本限制。

相同模型、提示版本、数据与问题复用结果。请求前预留预算，返回后按usage核算保守估计；常见未计费4xx不占预算。价格参考2026-09-08官方定价（https://api-docs.deepseek.com/quick_start/pricing/），人民币预算采用保守上界估计，不是官方账单；沿用每天1元、每月5元上限。无自动后台AI调用。

验证：28项数据/AI测试，90项跨设备交互测试，类型检查与生产构建。AI测试使用模拟提供方，覆盖证据校验、缓存、预算拦截和结果展示；真实本地数据预览包含17篇稿件与30天账号记录。当前未配置DeepSeek Key，因此真实提供方的生成质量和连通性尚未验证，须由用户在账号面板填Key后测试。
