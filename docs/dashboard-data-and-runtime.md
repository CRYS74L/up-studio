# 数据看板：数据口径与本地目录

## 目录与运行

项目运行文件、数据库、Node、日志、发布目录、回滚文件、图片与 pnpm 缓存均位于项目的 `.local-runtime/` 内，该目录不提交 Git。

pnpm 11 使用 `pnpm-workspace.yaml` 的 `storeDir`。原 `D:\.pnpm-store` 已迁至 `.local-runtime/pnpm-store`，逐文件核验 17356 个文件并通过离线安装。用户指出的乱码目录为空目录结构，已迁至 `.local-runtime/artifacts/garbled-path-recovery`。迁移清单保存在 `.local-runtime/artifacts/`。

Windows 自启任务仍为 `BilibiliCreatorInsights-Local-25758`，只启动项目内的 `ServiceHost.exe`。更新通过 `runtime/update.ps1` 完成，保持其他自启项不变。系统的任务注册记录属于 Windows 自启机制，程序文件不放在系统目录中。

## 概览与比较

- 粉丝量：账号粉丝总量，来自 fans/stat/num 的 total_num，不使用稿件涨粉之和。
- 播放量：本批稿件累计播放之和；平均播放量按稿件数计算。
- 平均互动量：每篇的点赞、评论、弹幕、收藏、投币、分享之和，再按稿件数平均；缺失任何分项时不假装完整。
- 每项独立选择比较基准：上月同日，缺失则上周同日，再缺失则昨天；月末按实际月份天数截断，不按自然月汇总。标签使用“相比上月”等。
- 封标点击率采用创作中心的星级展示，数值为 tm_star / 10。tm_rate 不能作为绝对点击率；绝对曝光与百分比点击率仍保持不可用。排行动态设置坐标范围，两端圆角，悬停查看完整标题与原值。

## 联合分析

组合图包含账号新增关注/取消关注双折线、播放柱/涨粉线、播放柱/互动线、观看组合图、自定义最多四层指标。各指标保留自己的单位和坐标轴。

观看图按投稿从旧到新排列，完整标题换行并允许横向滚动。柱表示平均播放百分比，折线可切换平均播放时长或 3 秒跳出率。“平均播放时长与完播率”为用户指定标题，其中播放百分比不等同于完整看完人数比例。

## 稿件数据

已对照登录中的创作中心数据总览、播放分析、转粉分析与粉丝分析页面：

| 内容 | 保存和展示 |
| --- | --- |
| 发稿后 48 小时 | hour_tendency |
| 发稿后 30 天 | tendency |
| 近 30 天 | last_30_day_tendency，展示最新 30 天 |
| 长期日趋势 | 合并历次 first30d 和 recent30，有效日期永久保留 |
| 实时小时窗口 | hour_realtime_tendency 独立保存，不冒充首月日趋势 |

| 年龄 | 源页面标签：小于16、16–25、25–40、大于40 |
| 地域与兴趣 | 地域全部展示，兴趣显示权重，全部标签可展开 |
| 选题偏好 | 粉丝/游客，全站/分区切换；这是近期多稿件分析 |
| 游客转粉 | 游客播放、稿件涨粉、播转粉率与源页面解读 |
| 留存与弹幕 | 本稿/同类曲线、互动弹幕时刻、参与人数与均分 |
| 细分指标 | 粉丝/游客点击星级、跳出率、互动率与常规互动分项 |

历史库从既有快照回填，并在每次成功采集后追加。未曾采集且源平台已不再提供的日期无法恢复；曲线对这些间隔断开，不补零或插值。源平台返回的同类留存负数视为无效，不显示为真实比例。

## 验证

2026-09-07：24 项单元测试，桌面/手机/平板 45 项交互回归，类型检查与生产构建通过。真实同步成功处理 17 篇稿件，132 次请求；账号历史 90 天。抽检稿件有首月 30 点、首 48 小时 48 点，日历史合并后 84 点。实际页面核对粉丝总量 3382，粉丝比较上月，其余概览指标回退比较昨天。

界面使用明亮粉、青、紫、黄、绿图表色；深色模式独立文字与图表配色，主题交叉淡入，分段控件使用单一可打断滑块，响应减少动态效果设置。
