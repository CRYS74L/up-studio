# 云盘备份与恢复

## 当前可用范围

网站服务仍运行在当前本机；备份目标是用户关联的 Google Drive 或 WebDAV 云盘目录（包括第三方挂载的 123 云盘），不是把“云盘备份”替换成本地备份。

第四张卡片位于数据源页面左下方。支持多个连接、手动备份、每天自动备份、列出恢复点、下载校验及确认恢复。未配置连接时不会上传任何业务数据。

备份执行层使用 rclone 与 restic。当前本地 Node 服务已集成；普通 Node 服务器可安装相同工具使用此引擎。纯 Cloudflare Workers/D1 无法直接运行这些原生工具，本次没有伪装成已支持该部署；Worker 的备份接口会明确报告未接入执行服务。选定 Cloudflare 后需要独立执行服务及 D1 导出/导入适配，不能直接复制本地 SQLite 恢复代码到 D1。

## 关联

- Google Drive：点击授权，在浏览器完成 Google 的同意流程；指定专用文件夹的链接或 ID。授权入口使用 rclone 自带的 Google 连接器，不会自动打开系统默认浏览器。
- 远程服务：本机回环授权不适用于未转发授权端口的远程服务器，可在有浏览器的电脑运行 `rclone authorize drive`，在高级选项导入返回的 JSON。令牌只加密保存在服务端，不会出现在状态接口。
- WebDAV：填写服务地址、账号、密码，以及相对于该地址的专用文件夹。123 云盘需先由用户配置可读写的 WebDAV 挂载服务。本工具不获取或绕过 123 云盘账号授权。
- 初次关联使用已创建的空文件夹；若已有本应用的 restic 仓库，则使用原备份密码。不会覆盖不属于备份仓库的已有文件。
- 云盘操作固定以所选 Google folder ID / WebDAV 路径为根，不允许 `..`、绝对路径或编码分隔符逃逸。备份数据和 restic 的索引、锁、密钥等文件都在指定文件夹内部。

## 数据与安全

备份包含所有账号的业务数据库，以及恢复加密凭据所需的主密钥、相关应用设置。整个备份仓库由 restic 加密；必须独立保存备份密码。忘记密码不能让 AI 或后台绕过解密。

restic 仓库格式 2 使用无损压缩和内容寻址去重，多次备份复用相同数据块。主数据库已有的无损压缩同样保留。不自动删除任何云端恢复点。

连接凭据与备份密码使用 AES-256-GCM 保存于独立的 `cloud-backup/connections.enc.json`；密钥为 `cloud-backup/vault.key`。该目录必须受服务账号的文件权限保护，不能公开或提交 Git。它不依赖业务数据库，因此数据库损坏时仍可连接云盘。换机后可以重新关联同一目录，并输入原备份密码恢复。

每次备份通过 SQLite 在线备份生成一致性副本，再校验数据库、内容块及加密凭据。上传结束后，从远端回读整个恢复点并比较 SHA-256；通过后才显示“已校验”。临时明文工作文件位于受限的工作目录，任务结束即清理。

## 恢复流程

1. 选择云盘和恢复点。
2. 完整下载，验证 restic 数据、SQLite 完整性与外键、压缩数据块与快照校验和、凭据与恢复密钥，以及数据库版本兼容性。
3. 显示日期、账号数、稿件数、快照数、会话数。此时不修改当前数据库。
4. 用户输入“恢复数据”确认，暂停新数据请求，等待进行中的写入结束。
5. 将当前数据库、配置及相关 WAL 文件保留在 `cloud-backup/safety/`，写入恢复日志后替换数据库与必要配置，再恢复服务。

恢复预览有效期为 15 分钟，过期后需要重新校验。恢复失败不会显示成功；启动时会处理未完成的恢复日志。恢复前副本不会自动删除。

若主数据库打不开，服务仍提供静态页面及 `/api/backups/*` 恢复接口，其余数据接口明确返回 503。打开数据源页面即可进入恢复流程。操作系统或整个安装目录丢失时，先重新安装服务和工具，再关联同一云盘目录与密码；不需要 AI 参与。

## 工具部署

工具可由 PATH 或环境变量 `UP_STUDIO_RCLONE`、`UP_STUDIO_RESTIC` 指定，也可在运行目录的 `backup-tools.json` 中指定绝对路径。此文件与可执行文件不纳入 Git。当前准备的版本：

- rclone 1.75.1，官方 Windows AMD64 压缩包 SHA-256：`200eb602c126d82aa38b51e0f6b9ae837473ff99b51278d3f6f837574c494d6e`
- restic 0.19.1，官方 Windows AMD64 压缩包 SHA-256：`da948ad707ed690426473aaba2046cd61f8f90f6f0e7dab6be0d5796531de67d`

本机工具位于 Common 下各自的版本目录。Linux 服务器安装对应的官方构建。现有服务默认只监听本机地址；远程部署还必须配置相应的访问控制和 HTTPS，不能把本地接口直接裸露到公网。

## 验证

`npm run test:cloud-backups` 会执行构建、路径边界/凭据加密/恢复日志测试，以及隔离的真实 rclone WebDAV + restic 集成测试。该 WebDAV 仅是测试替身，测试不连接用户的真实云盘。

已覆盖：指定文件夹外文件保持不变、第二次相同内容仅上传变化的数据块、不重复整库上传、备份回读校验、数据库损坏后 HTTP 恢复入口仍可用、确认前不改动数据库、错误确认被拒绝、恢复后指标和凭据恢复正常、远端数据篡改被拒绝、取消 Google 授权后清理会话。

真实 Google Drive / 123 云盘的网络权限、服务限额及账号授权必须在用户关联后验证；本次没有登录用户云盘或上传真实业务数据。

参考：[restic](https://restic.net/)、[rclone Google Drive](https://rclone.org/drive/)、[rclone WebDAV](https://rclone.org/webdav/)。
