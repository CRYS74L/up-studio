# 数据看板整体改造

用户已开启项目开发模式，并授权由实现者判断具体设计与取舍。基线为 main / e0c909d / v0.1.0-dev.11，本地与私有远程一致。

## 设计与验收

用户进一步指定尽量贴近 iOS / iPadOS，原企业工作台概念作废。采用分组白色内容、系统大标题、悬浮半透明侧栏与移动底栏、粉色强调、分段控件，并完整支持深色模式。首页按标题与同步操作、快照时效、三列两行（移动端两列三行）核心指标、可切换稿件表现图、最近发布列表和数据健康排列。稿件详情、内容矩阵、联合分析和数据源沿用同一套字号、间距、控件和状态反馈。概念图只提供视觉参考，所有数值仍来自实际 API。

保留 React / Vite / ECharts / Hono / D1；不迁移或覆盖现有数据。取不到的字段保持 null；新旧快照不伪装成实时数据。不擅自完成需要账号授权的云端部署、Drive OAuth 或向 AI 发送私有数据。

## 实施清单

- [x] 数据可靠性：worker/bilibili.ts 的所有请求共用并发上限、退避重试、业务错误优先解析；校验分页总数与重复稿件；保留局部失败诊断。worker/bilibili.test.ts 覆盖真实错误形状。
- [x] 汇总正确性：worker/summary.ts 对缺失观看数据使用有效权重，不把缺失互动视为零；按 Asia/Shanghai 的上一个自然月最后有效快照比较，展示实际日期，缺失上月数据则不计算变化。
- [x] 页面重构：拆出概览、图表生命周期和可靠性辅助模块；使用与概念一致的布局、明暗主题与响应式控件。
- [x] 交互：URL 保留页面及稿件定位、BV 搜索、搜索后有效选中、分析清空不反弹、重试与同步反馈、移动导航、可访问弹层。

- [x] 实际验收：单元测试、类型检查、构建；浏览器桌面/移动、主题切换、搜索与选中、分析筛选、错误和空状态；一次真实采集并如实报告接口限制。

## 复核补充

同页 Insights 跳转与浏览器返回同步稿件选中；汇总和稿件按 capturedAt 同批次查询。图表隐藏时延迟初始化，切换分组后通过 ResizeObserver 获取真实尺寸。增加快照导出与自动刷新测试。本轮未扩张云端账号授权范围。

用户补充：大标题收敛到 28–30px，核心数字 27–28px，界面与图表最小文字提高至 12px；概览变化改为上月基准。覆盖跨年和闰年月份边界测试。
