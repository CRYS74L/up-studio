# 独立本地部署与创作空间重构

用户授权：独立本地稳定运行；仅新增专属于本项目的登录自启，绝不修改现存自启项。完全重做稿件、分析和数据源的结构与交互，不受旧界面约束。保留 28–30px 标题和至少 12px 辅助文字。最新色彩修正为明亮清新，不使用浓烈玫红。

## 工作清单

- [x] runtime：固定 Node 运行时、编译后 Worker 与静态资源、独立 SQLite 数据、原库安全迁入、轮转日志、定时采集、健康接口、唯一计划任务、停启及异常恢复、启动项前后哈希核验。
- [x] studio：全新应用壳与单一设计系统，浅粉/青/蓝/紫语义色，系统字体、弹簧选择反馈、对称抽屉转场、减少动态效果与键盘焦点。
- [x] 稿件：网格/列表浏览、标题/BV 搜索、时长筛选、单选独立详情、多选进入分析；详情按问题分组，包含真实观众维度和留存数据。
- [x] 分析：统一稿件选择器、指标选择器；作品对比用独立单位图表，真实时间趋势与关系散点、原始数据表；缺失保持为空。
- [x] 数据源：独立服务状态、连接管理、手动同步、质量清单和采集历史；技术细节按需展开。
- [x] 验收：逻辑与 UI 用例、编译、真实服务、持久数据库、任务父链、自启保护、已编译发布升级、Chrome 预览；不能关闭 Codex/重启电脑测试，需如实保留这一验证边界。

部署目录限定为项目内 `.local-runtime`，源代码为 `runtime/` 与 `src/studio/`。现存数据不覆盖，已有运行项不改动。最终由主代理统一提交、打 annotated 开发标签并推送。

验收补充：Windows失败重启未按预期执行，已改为常驻监督进程自行退避恢复；异常子进程恢复已实测。正常停止在服务退出后结束唯一任务实例。升级等进程和任务全部停止；回滚恢复5个具体文件且不回退数据库。独立审查报告的3项P2均已修复。
