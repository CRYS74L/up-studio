# 当前字体的内嵌基线

这些 WOFF2 来自 2026-09-10 本机页面实际使用的字体文件。没有替换为相似字体，没有裁减字符集，也没有修改字形、advance width、字距、行高指标或 OpenType 排版表。原字体名称和版权元数据保留在文件中。

| 使用位置 | CSS 名称 | 原字体 |
| --- | --- | --- |
| 页面文字 | UP Studio UI | 当前安装的 PingFang SC |
| 图表文字 | UP Studio Chart | Microsoft YaHei UI |
| 兴趣词云 | UP Studio Cloud | Microsoft YaHei |

本机这组苹方的文件名与字重不一致：实际常规来自 `PingFangSC-Light_1.ttf`，实际粗体来自 `PingFangSC-Medium_1.ttf`，特粗来自 `PingFangSC-Semibold_1.ttf`。不能按文件名重新分配字体；当前应用使用的 400、450、500、520 对应常规，550–730 对应粗体。这一对应关系经过浏览器实际渲染比对。

图表与词云原来分别使用 `system-ui` 和 `sans-serif`，本机实际解析为微软雅黑 UI 和微软雅黑。两者分别保留，避免中文字形相同但垂直指标不同造成位移。

`manifest.json` 记录每个文件的 SHA-256、原始文件 SHA-256、TTC 集合索引和字形数量。文件用 FontTools 4.64.0 的 WOFF2 编码转换，保持原时间戳和字形边界；未执行子集化、简化、重绘或字重修正。

页面常规和粗体预加载，图表及词云在首次使用时加载各自字体，完成后才测量和绘制。文件名包含内容哈希，本地服务允许长期缓存。`@font-face` 不使用 `local()`，已安装其他版本字体的设备仍加载同一文件。

验收：本机 Chromium 中，三种字体、4 个字号（12/14/28/45）、15 个实际字重组成的 180 项中英文混排矩阵，在内嵌前后截图逐像素一致。字体表比对确认 cmap、hmtx、hhea、OS/2、GPOS、GSUB、name 保持一致。不同操作系统的抗锯齿仍由各自浏览器和系统决定，不能把同一字体文件等同于跨系统截图逐像素相同。
